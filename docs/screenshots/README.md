# Screenshots to capture

No screenshots are committed yet. Capture these for the README, the docs and the Play listing.

**Capture settings**
- Phone in portrait unless noted, 1080 px wide or more, PNG.
- Connected to a computer, so status pills show a host name (use a neutral name like "Laptop").
- Dark theme with dynamic color for the main set; one light-theme shot of the Connect screen.
- Hide personal notifications; use a clean status bar (`adb shell settings put global sysui_demo_allowed 1`, then
  demo mode).
- Play requires 2–8 phone screenshots, 16:9 or 9:16, each side 320–3840 px. Tablet shots (7" and 10") are
  optional but help the tablet listing.
